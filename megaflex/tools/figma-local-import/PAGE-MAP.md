# Карта исходного проекта MEGAFLEX

## Технологии и источники

Это отдельный статический проект `megaflex-website`, а не Next.js-приложение из `C:\open-design`. Фактический сайт: HTML + CSS + vanilla JavaScript. Нет маршрутизатора, серверных страниц или CSS-фреймворка.

| Путь относительно сайта | Назначение |
|---|---|
| `dist/index.html` | Единственная страница, семантические секции, карточки, контакты, HTML dialog |
| `dist/styles.css` | Палитра, типографика, layout, responsive rules, состояния hover/focus |
| `dist/fonts.css` | Локальные Inter 400 / 500 / 600 / 700 |
| `dist/app.js` | Меню, восемь описаний продукции, окна компании/конфиденциальности/соцсетей |
| `dist/assets/*.png` | Реальные фотографии и растровые логотипы |
| `dist/assets/*.svg` | Исходные outline-иконки |
| `dist/assets/inter-*.ttf` | Шрифты; лицензия рядом |
| `preview.ts` | Локальный preview; для подготовки плагин использует собственный временный loopback server |
| `design/figma-source.tsx` | Историческая выгрузка; не является runtime сайта и не подменяет текущий HTML |
| `tools/figma-local-import/` | Все новые файлы переноса и результаты; отделены от сайта |

## Страница `/`

| Блок | CSS/HTML | Состав |
|---|---|---|
| Header | `.header` | PNG логотип, навигация, телефон, CTA, мобильное меню |
| Hero | `.hero` | Eyebrow, многоцветный H1, текст, две кнопки, фото рулона, синяя плашка, 4 преимущества |
| Products | `#products` | Вступление, ссылка, 8 карточек продукции |
| About | `#about` | Текст компании, CTA, фото комплекса, 4 факта |
| Benefits | `.benefits` | Заголовок, 6 карточек |
| Production | `#production` | Вступление, карточка контроля качества, 4 этапа |
| Contacts | `#contacts` | Два телефона, два email, WhatsApp, фотография, слоган; формы нет |
| Footer | `.footer` | Инверсный PNG логотип, меню, контакты, 2 соцсети, copyright, конфиденциальность |

Навигационные ссылки ведут к якорям этой же страницы. «Весь каталог» также ведёт к существующей сетке, отдельного маршрута каталога нет. Ссылки tel, mailto, WhatsApp открывают внешние приложения.

## Повторения и компоненты

- 8 Product Cards, 6 Benefit Cards, 4 Stage Cards;
- Contact Item (телефон, email), WhatsApp Button;
- обычная/вторичная кнопка, Icon Button, Navigation Item;
- одинаковые поддеревья с одинаковыми стилями и размерами переиспользуют основной компонент в пределах фрейма;
- отличающиеся адаптивные размеры не принудительно унифицируются;
- Header и Footer сохраняются именованными контейнерами: в исходном сайте они встречаются по одному разу на страницу.

## Адаптивные композиции

CSS содержит `min-width:1440px`, `max-width:1250px`, `max-width:980px`, `max-width:680px`, `max-width:360px`. Подготовлены 1440, 1200, 768, 390, 320 px. Высота viewport при измерении — 1000 px; высота полного фрейма берётся из реального документа.

- 1440: 12 колонок, контейнер 1280, поля 80; товары 4 колонки.
- 1200: уменьшенные поля и шрифты, контакты в столбик внутри левой части.
- 768: мобильное меню, товары и преимущества 2 колонки, производство под вступлением.
- 390: Hero в столбик, преимущества/этапы по одной колонке, товары 2 колонки.
- 320: товары и факты по одной колонке, CTA Hero вертикально, contact visual в столбик.

## Дополнительные состояния

В `app.js` действительно реализованы 12 диалогов: восемь товаров, компания, конфиденциальность, сообщения Instagram и Telegram (официальные ссылки соцсетей в исходнике отсутствуют). Каждый снят при 1440 и 390 px. Отдельно подготовлен mobile menu open. Эти 25 состояний импортируются только по флажку.

Ни UI Kit как самостоятельного материала, ни интерактивной схемы Prototype, ни Mind-map в источнике нет. Они не добавляются. Hover, focus и JS-переходы не превращаются в выдуманные страницы.

## Точность источников

`data/reports/capture.json` содержит SHA-256 каждого файла `dist/`, общий fingerprint и количество узлов каждого макета. Подготовка сверяет файлы до и после захвата. Внешние ресурсы не подменяют локальные изображения. Снимки экрана находятся в `data/references/` и используются только для сравнения.
