## Известные границы

- Grid и декоративные наложения сохраняются точными координатами, а не везде Auto Layout.
- Логотипы — исходные PNG. Фотографии заменяются через Image Fill, но их содержимое не становится вектором.
- Диалоги подготовлены отдельно от backdrop blur. JS-навигация, hover-анимации и интерактивный прототип не импортируются.
- Фиксированные Text Nodes сохраняют исходные размеры; для более длинного нового текста может потребоваться увеличить слой или включить auto-height вручную.
- Повторное обновление заменяет выбранную группу целиком. Для сохранения внесённых в неё правок используйте новую версию.
- Для транзакционной сборки нужна временная страница Figma. При лимите страниц используйте пустой файл.
- Сетевые запросы плагина запрещены manifest. Все данные импортируются локально.

Корневые команды `C:\open-design` не запускались: изменён только отдельный standalone-проект `megaflex-website`, его исходный сайт не менялся.
