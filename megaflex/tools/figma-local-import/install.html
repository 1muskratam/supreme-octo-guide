Собственный ID плагина

Этот помощник работает локально и ничего не отправляет в интернет.

  1. В приложении Figma откройте Plugins → Development → New plugin (или Create new plugin).
  2. Создайте плагин для Figma Design с интерфейсом. Сохраните заготовку в отдельную пустую папку, чтобы Figma не перезаписала готовый плагин.
  3. Выберите ниже manifest.json из новой заготовки. Помощник возьмёт только выданный Figma ID.
  4. Сохраните полученный manifest.json в папку готового MEGAFLEX-плагина, заменив существующий файл.
  5. Figma → Plugins → Development → Import plugin from manifest → выберите заменённый manifest.json.
Ожидаю manifest.json из заготовки Figma.
