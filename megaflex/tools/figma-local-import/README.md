# MEGAFLEX — локальный перенос сайта в Figma

Плагин строит редактируемые Figma-слои из **существующего сайта**. Он не вставляет скриншот страницы вместо дизайна. Сеть, токены Figma, MCP и REST API не используются. Файлы сайта в `dist/` не изменяются.

**Статус на 29 октября 2026:** плагин зарегистрирован с собственным ID 1697198624057751377 и запущен в настольной Figma. Полный импорт 30 макетов выполнен на странице MEGAFLEX / Website. Визуальная проверка выявила лишние переносы однострочных подписей и выход мобильных экспортов за границы фрейма; алгоритм исправлен, проводится повторная проверка. Смотрите TEST-REPORT.md.

## Установка без программирования

1. Откройте **настольное приложение Figma**, войдите в свой аккаунт и создайте пустой **Design file**, который вы можете редактировать.
2. Откройте **Plugins → Development → New plugin / Create new plugin**. Создайте плагин для **Figma Design** с интерфейсом. Сохраните заготовку **в отдельную пустую папку**, не поверх готового MEGAFLEX-плагина.
3. Дважды щёлкните **install.html** в папке MEGAFLEX-плагина. В открывшемся локальном помощнике выберите `manifest.json` из заготовки, созданной Figma. Нажмите «Сохранить готовый manifest.json».
4. Сохраните скачанный `manifest.json` **в папку MEGAFLEX-плагина**, рядом с `code.js` и `ui.html`, заменив исходный manifest. Если браузер скачал `manifest (1).json`, переименуйте его в `manifest.json` после переноса.
5. В Figma выберите **Plugins → Development → Import plugin from manifest** и укажите этот заменённый `manifest.json`.
6. Запустите **MEGAFLEX — Local editable import** из меню Development.

Собственный ID нужен для регистрации development plugin. Он не является токеном или паролем. Это стандартный механизм Figma: [Plugin Manifest](https://developers.figma.com/docs/plugins/manifest/). Помощник install.html работает без сети. После получения ID заготовка больше не нужна для работы готового плагина.

## Первый запуск: сначала тест

1. В интерфейсе плагина выберите **data/design.json**. Изображения уже включены в JSON; сервер не нужен.
2. Нажмите **«2. Тест элементов»**. Будут созданы контейнер, исходный заголовок, фотография, кнопка и контактный блок с вложенными слоями.
3. На холсте проверьте:
   - двойным щелчком можно изменить текст, размер и цвет;
   - у фотографии есть **Fill → Image**, изображение можно заменить;
   - у кнопки есть редактируемые текст и векторная стрелка;
   - контактный блок содержит отдельные иконку, подпись и телефоны;
   - шрифт Inter отображается правильно, слои не перекрываются.
4. Если тест выглядит правильно, отметьте подтверждение в плагине. Если нет — **не подтверждайте**, пришлите текст ошибки или экспорт теста для исправления.
5. Нажмите **«3. Импортировать сайт»**. Дождитесь сообщения о завершении. Интерфейс показывает текущий макет и количество элементов; доступна отмена.
6. Нажмите **«4. Экспорт PNG и отчёта»**. Сохраните PNG по появившимся ссылкам и `figma-report.json`. Они нужны для окончательной проверки соответствия.

После закрытия и нового запуска плагина тест выполняется снова. Это намеренная проверка среды Figma, шрифтов и текущего пакета данных.

## Что подготовлено

В исходниках существует **одна страница `/`**, а не отдельные страницы каталога, компании или контактов. Основные фреймы:

| Фрейм | Размер CSS px | Основание |
|---|---:|---|
| Home / Desktop | 1440 × 5175 | Полная desktop-композиция |
| Home / Laptop | 1200 × 5282 | Правила max-width: 1250px |
| Home / Tablet | 768 × 6994 | Правила max-width: 980px |
| Home / Mobile | 390 × 9328.77 | Правила max-width: 680px |
| Home / Mobile Compact | 320 × 11000.77 | Правила max-width: 360px |

PNG округляет дробную высоту до целого пикселя. Каждый фрейм содержит **Header, Hero, Products, About, Benefits, Production, Contacts, Footer**. Контакты сохранены без формы: телефоны, e-mail и WhatsApp.

Флажок дополнительных состояний добавляет **25** реально существующих состояний: открытое мобильное меню и 12 диалогов на desktop и mobile (8 товаров, компания, конфиденциальность, Instagram, Telegram). Диалоги импортируются как отдельные карточки, без затемнения и размытия лежащей под ними страницы. Это не дополнительные маршруты сайта.

UI Kit, Prototype и Mind-map как отдельные страницы не создаются: таких исходных материалов в проекте нет. Компоненты располагаются справа от соответствующего фрейма в `Source components`. Фреймы и библиотека помещены в явно обозначенную группу импорта на странице `MEGAFLEX / Website`.

## Редактирование

- Основные тексты — **Text Nodes**, включая многоцветный заголовок Hero.
- Все 16 уникальных исходных PNG — **Image Fills**. На странице 17 размещений фотографий и логотипов; некоторые изображения используются повторно.
- Исходные SVG и WhatsApp — векторные слои, не снимки экрана.
- Buttons, WhatsApp Button, Contact Item, Product Card, Benefit Card, Stage Card, Navigation Item и Icon Button создаются как компоненты и экземпляры. Текстовые свойства доступны в свойствах экземпляра. Компоненты с различающейся геометрией остаются самостоятельными, чтобы не растягивать исходный дизайн.
- Создаются локальные стили цвета и типографики. Имена учитывают фактические размеры, начертания и адаптивные варианты.
- Для линейных контейнеров используется Auto Layout, если он воспроизводит исходные координаты с погрешностью не более 1 px. Сетки и сложные наложения сохраняют точное позиционирование. Не все контейнеры автоматически растягиваются при произвольной смене ширины: для адаптивных состояний подготовлены отдельные фреймы.
- В desktop-фрейме есть скрытая 12-колоночная сетка: поля 80 px, gutter 24 px.
- Редактируйте экземпляр или его основной компонент справа от страницы. Чтобы переместить внутренний элемент экземпляра свободно, при необходимости используйте **Detach instance**. Изображения и текст можно заменять без detach.

## Шрифты

Исходный сайт использует локальные **Inter Regular, Medium, Semi Bold, Bold**. Перед импортом плагин вызывает `figma.loadFontAsync()` для каждого начертания. Недоступный шрифт останавливает импорт до создания макетов.

Предпочтительно установить четыре TTF из исходной папки `dist/assets/inter-0.ttf` … `inter-3.ttf` (в готовом архиве они продублированы в `fonts/` с лицензией) и перезапустить Figma. Если установка невозможна, плагин предлагает список доступных шрифтов; замена применяется только после вашего явного подтверждения и записывается в отчёт. При fallback визуальное соответствие нужно перепроверить.

## Повторный импорт

**Обновить:** заменяет выбранные ранее импортированные группы после успешной сборки новых. Ручные правки внутри заменяемых групп будут заменены данными сайта. Остальные слои не удаляются. Дополнительные состояния, если их флажок выключен, не затрагиваются.

**Новая версия:** сохраняет предыдущие группы, добавляет новые с датой. Если накоплено несколько версий, режим обновления обновляет последнюю группу с этим ключом в порядке слоёв. Старые версии сохраняются намеренно; для продолжения с резервной копией используйте новую версию.

Отмена и ошибки построения убирают временную страницу, сохраняя предыдущую версию. Для временной страницы необходим свободный лимит страниц Figma — поэтому для первого запуска рекомендуется пустой файл. Слои вне групп импорта не используются как место назначения.

## Проверки и ограничения

Подробности: [TEST-REPORT.md](TEST-REPORT.md), [PAGE-MAP.md](PAGE-MAP.md), `data/reports/capture.json`.

Локально проверены TypeScript по официальным типам Plugin API, девять автоматизированных тестов на модели API, интерфейс плагина в браузере, сохранность исходников, изображения и снимки всех подготовленных состояний. Восстановление промежуточного JSON в браузере сравнено со скриншотами сайта: размеры совпадают; доля пикселей с отклонением более 24/255 составляет 0.07–0.15%. **Это проверка извлечения данных, не доказательство совпадения в Figma.**

Запуск в Figma и редактируемость проверены; окончательные результаты сравнения экспортов приведены в TEST-REPORT.md. Возможны отличия текстового движка, сглаживания и теней Figma. Шрифт с тем же именем может отличаться версией. Изображения импортируются с исходным центрированным crop; все изображения этого сайта имеют object-position 50% 50%. Логотипы остаются исходными PNG, их нельзя редактировать как вектор. Работающий JS, анимации и навигация в прототип не преобразуются; адреса ссылок сохраняются в метаданных слоёв. Сложное затемнение/blur под диалогами отдельно не переносится.

## Для повторной подготовки из обновлённых исходников

Нужны Node.js 24+, pnpm и установленный Chrome. Команды выполняются **в этой папке**, не в корне Open Design:

```powershell
pnpm install
pnpm prepare-data
pnpm build
pnpm typecheck
pnpm test
```

`prepare-data` запускает временный сервер только на `127.0.0.1` со случайным портом, читает `../../dist`, использует Playwright и закрывает сервер. Исходники не переписываются. `CHROME_CHANNEL=msedge` позволяет выбрать Edge при подготовке. Все данные, скриншоты и отчёты пишутся сюда в `data/`.

Сравнение PNG после фактического импорта:

```powershell
pnpm compare "C:\папка-с-экспортами-Figma"
```

В папке должны быть PNG с выданными плагином именами и `figma-report.json`. Скрипт проверяет fingerprint исходников, создаёт `data/comparison/results.json` и изображения различий. Оценивать нужно прежде всего переносы строк, фото, Header, Hero, сетку, Contacts и Footer. Процент отличий сам по себе не заменяет просмотр.

Для отдельной проверки промежуточного JSON:

```powershell
node scripts/verify-extraction.ts
node scripts/compare.ts data/extraction-check --extraction
```

Собственный ID также можно установить командой `pnpm set-id "C:\папка-заготовки-Figma\manifest.json"` вместо install.html.

`src/*.ts` — исходники; `code.js` — сгенерированный совместимый runtime для Figma, не редактируйте его вручную. `ui.html` и `install.html` самодостаточны. Все зависимости зафиксированы в `pnpm-lock.yaml`. На машине пользователя для запуска готового плагина Node.js и зависимости не требуются.

Официальные источники: [Plugin API](https://developers.figma.com/docs/plugins/api/figma/), [Manifest и собственный ID](https://developers.figma.com/docs/plugins/manifest/). Версия типов при сборке: `@figma/plugin-typings 1.142.0`.
