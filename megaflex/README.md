# MEGAFLEX — сайт на коде

Самостоятельный статический сайт по Figma: https://www.figma.com/design/2XavqY0fgbtiIgZ30Zo5YH?node-id=2-53

## Запуск
Установите Node.js 24 или новее, затем из этой папки выполните:
```
node preview.ts
```
Откройте http://127.0.0.1:4387. Установка зависимостей не нужна.
Для другого порта задайте переменную PORT.

## Что редактировать
- `dist/index.html` — все секции, тексты, телефон, e-mail, адреса ссылок.
- `dist/styles.css` — CSS-переменные бренда, сетка, компоненты, адаптив.
- `dist/app.js` — меню, карточки продукции, модальные окна.
- `dist/assets/` — локальные изображения и SVG из Figma, локальный Inter.
- `dist/fonts.css` — начертания шрифта.
- `design/figma-source.tsx` — полученный исходный контекст макета, справочный материал; не исполняется.
- `.openai/hosting.json` — конфигурация приватного размещения Sites.

## Размещение
Содержимое `dist/` можно разместить на любом статическом хостинге. Сборка не требуется.
Все ассеты локальные; сайт не зависит от временных URL Figma.

## Реализовано
8 секций макета, адаптивная сетка, мобильное меню, клавиатурный фокус, диалоги карточек.
В контактах вместо формы — два телефона, две почты и WhatsApp на +7 777 677 29 29.
Все основные CTA ведут к соответствующему разделу. Телефоны используют tel:, почта mailto:.
Карточки открывают описание и позволяют перейти к контактам.

## Перед публичным запуском
Приватная версия предназначена для согласования. Иллюстрации производства перенесены из макета; они не являются подтверждённой фотосъёмкой реального объекта.
Официальные URL Instagram и Telegram не предоставлены — иконки честно сообщают об этом и предлагают прямые контакты. Добавьте подтверждённые URL в HTML и уберите соответствующие обработчики в app.js.
Текст конфиденциальности описывает текущий сайт без формы; согласуйте его с владельцем перед публичным запуском.
Лицензия шрифта Inter: SIL Open Font License 1.1 (см. dist/assets/Inter-OFL.txt).


## Полный комплект проекта

- tools/figma-local-import/ — локальный Figma-плагин, TypeScript-исходники, готовый code.js, manifest.json и инструкция.
- tools/figma-local-import/data/design.json — готовый набор 30 макетов с изображениями.
- tools/figma-local-import/data/ — эталонные скриншоты, экспорты Figma и результаты сравнений. Статус проверки указан в TEST-REPORT.md.
- design/original/ — архив исходных визуалов, спецификации и материалов первого макета. Старые figma-*.js сохранены как справочные материалы; для текущего переноса используйте только локальный плагин.
- qa/ — снимки сайта для проверки.
- FILES.sha256 — контрольные суммы файлов комплекта.

Зависимости node_modules, внутренняя история Git и дублирующие ZIP/TAR-архивы не включены. Исходный сайт сохранён без изменений. Файлы остальных проектов репозитория расположены вне этой папки.
